# Current published Datapizza benchmark records

These are exact records from the selected current CPU runs. Generated answers and retrieval order are preserved. `judge_input.jsonl` is blinded and `review_template.jsonl` is unscored; no historical judge grades were reused. The four reranker cells stopped before question execution and are recorded in `blocked-scenarios.json`. `environment.json`, `dependency-versions.txt`, `selection.json`, per-run manifests, and `checksums.sha256` capture the run provenance. See `RESULTS.md` for the comparison and limitations.
